Detailed Description

A VolumeLoader that computes each frame on the fly via a callable.

Useful for procedural data, simulations, or testing.

virtual std::shared_ptr< Volume > inviwo::ProceduralLoader::load ( size_t index,
std::shared_ptr< Volume > reuse,
std::stop_token stop ) const
overridevirtual

Load the volume at the given index. May be called from a background thread, hence implementations must be re-entrant and thread-safe.

Parameters
reusean optional volume whose storage may be reused to avoid reallocation. It may be null and must be ignored if its format or dimensions do not match the frame.
stopcancellation token. Implementations should poll stop.stop_requested() at natural checkpoints and return nullptr as soon as a stop is requested. A partially written reuse volume is discarded by the caller.
Returns
the loaded volume, or nullptr if the load was cancelled.

Detailed Description

template<typename T, size_t N = 1, bool Flat = false>
class inviwo::DataInport< T, N, Flat >

DataInport represents a general inport providing data as a std:shared_ptr<const T> If

Template Parameters
Nis set to 0 the port will accept multiple connections, and will provide a std::vector<std::shared_ptr<const T>> of data. If
Nis greater or equal to 0 exactly
Nconnections are accepted. If
Flatis set to true, the inport will also accept connections from outports with vector data of type
Tand merge them into the vector returned by getData().

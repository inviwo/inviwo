Detailed Description

Reads a single frame from a video file using ffmpeg.

Supported options

  • reader::option::index frame to read, std::ptrdiff_t, negative values count from the end, defaults to 0
  • videoreader::option::time time of the frame to read, std::chrono::duration<double>
  • videoreader::option::stream video stream to read, int, defaults to -1
